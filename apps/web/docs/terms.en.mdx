## What Zero Mail provides

Zero Mail is a Gmail productivity service that helps users reach inbox zero through AI-assisted triage, user-defined rules, labels, archive actions, read/unread changes, star actions, spam marking, digests, draft creation, and safe outbound workflows.

The core workflow is:

- You connect Gmail;
- You create natural-language or structured rules;
- Zero Mail stores the authoritative rule as structured When / Then configuration;
- Incoming messages are processed according to your enabled settings;
- Outbound actions either require your confirmation or must pass runtime safety gates before sending;
- Blocked outbound automation falls back to saving a Gmail draft.

Zero Mail does not permanently delete Gmail messages and does not invoke arbitrary external webhooks on your behalf.

## AI actions and outbound safety

Zero Mail can prepare and execute actions using AI. You remain responsible for the rules you create, the settings you enable, and the messages sent from your Gmail account.

Rule-triggered outbound actions are allowed only when all applicable conditions pass:

- The global Auto-send rules setting allows outbound automation;
- The specific rule is enabled and includes the outbound action;
- Sender trust checks pass;
- Per-account rate limits and daily caps pass;
- Idempotency checks confirm the same decision has not already sent the same message;
- Audit logging records the action.

If any gate fails, or if Auto-send rules is off, Zero Mail saves a Gmail draft instead of sending. Chat assistant send, reply, and forward actions require user confirmation through a preview card before execution.
