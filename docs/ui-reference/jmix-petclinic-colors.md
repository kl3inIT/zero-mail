## Color Takeaways

1. The brand identity is purple-first: `#867AEB`, `#6356C0`, `#584CAE`.
2. Yellow is the secondary accent: `#FFD042`, not a background theme.
3. Tables use very pale purple for hover/selection: `#DFDBFD`.
4. Event/status colors use pastel fill plus saturated text/border.
5. Dark mode keeps purple as the active/selected color but swaps the drawer background to dark charcoal.
