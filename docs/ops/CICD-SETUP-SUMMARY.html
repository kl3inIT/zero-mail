8. Infrastructure & Ops

  • Docker log rotation: 10 MB × 3 file = 30 MB max / container (YAML anchor x-logging trong compose).
  • Postgres backup: scripts/ops/backup/pg-backup.sh · daily 03:05 UTC qua cron · GPG/AES-256 · 7/4/6 daily/weekly/monthly retention · optional rclone off-host upload.
  • pg_stat_statements: shared_preload_libraries + log_min_duration_statement=500. Bật rồi, query analytics dùng được qua Postgres MCP.
  • Dev DB on VPS: role zeromail_dev + DB zeromail_dev, isolated (không access vào prod DB). Password rotated 2026-05-20.
  • SSH deploy key: ed25519 deploy bot, pub trong dat@VPS:~/.ssh/authorized_keys, private trong GitHub VPS_SSH_KEY secret (prod env).
