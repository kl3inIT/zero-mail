# Inbox Compact Attachments and Send Label

## Goal

Make Inbox composer attachments compact: no large attachment review area and no `blob:` preview tab. Show only the selected attachment count next to the attachment icon.

## Scope

- Remove inline attachment review block from Inbox composer.
- Keep attachment selection visible through a compact count on the attach button.
- Rename the composer submit button from "Create send preview" to "Send" / "Gửi" while preserving the existing confirmation-preview safety flow.
- Update i18n and the Inbox e2e spec.
