# Quick Task 260524-tc6: Unify Platform And BYOK LLM Provider Execution

## Goal

Refactor LLM provider execution so platform/admin routing and tenant BYOK use the same Spring AI provider execution layer. Credential ownership and billing policy remain separate.

## Scope

- Introduce a provider credential/executor contract shared by platform and BYOK paths.
- Route platform/admin LLM calls through provider credentials from admin master keys instead of a fixed `platformChatClient`.
- Make BYOK provider clients delegate to the same executor after BYOK endpoint validation.
- Preserve Spring Modulith boundaries: `core.llm` must not import `core.admin`.
- Cover runtime routing with tests so a 9router/OpenAI-compatible admin route uses its configured base URL/key.
