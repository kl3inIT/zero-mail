## Sampling Rate

- **After every task commit:** Run `pnpm --filter zeromail-web test -- --changed` (specs touching changed files only)
- **After every plan wave:** Run `pnpm --filter zeromail-web test && pnpm i18n:check && pnpm tsc --noEmit`
- **Before `/gsd-verify-work`:** Full suite green + Lighthouse mobile/desktop ≥ 90 + every row of `01.6-VISUAL-SWEEP.md` PASS
- **Max feedback latency:** ≤ 60 seconds for the per-commit quick run
