**A. Create `apps/web/features/landing/lib/setTheme.ts`** (verbatim from RESEARCH §3 + PATTERNS.md, with closed-enum guard):

```ts
'use server';

import { cookies } from 'next/headers';

export async function setTheme(formData: FormData) {
  const raw = formData.get('theme');
  const theme: 'light' | 'dark' = raw === 'dark' ? 'dark' : 'light';
  const cookieStore = await cookies();
  cookieStore.set('zm-theme', theme, {
    sameSite: 'lax',
    secure: process.env.NODE_ENV === 'production',
    httpOnly: false,
    maxAge: 60 * 60 * 24 * 365,
    path: '/',
  });
}
```

Cookie attributes per D-C3 are LOCKED — do NOT add `domain`, `priority`, or `__Host-` prefix. Closed-enum guard (`raw === 'dark' ? 'dark' : 'light'`) per RESEARCH §3 + KNOWN_ERROR_CODES pattern. DO NOT log the value (CLAUDE.md privacy convention #4).
