### `features/landing/lib/setTheme.ts` (Server Action)

**Analog:** No in-repo Server Action exists (this is the first one). Verbatim from RESEARCH §3 (lines 302-320).

**Source code** (RESEARCH §3):
```ts
// apps/web/features/landing/lib/setTheme.ts
'use server';

import { cookies } from 'next/headers';

export async function setTheme(formData: FormData) {
  const raw = formData.get('theme');
  const theme = raw === 'dark' ? 'dark' : 'light';
  const cookieStore = await cookies();
  cookieStore.set('zm-theme', theme, {
    sameSite: 'lax',
    secure: process.env.NODE_ENV === 'production',
    httpOnly: false,
    maxAge: 60 * 60 * 24 * 365,
    path: '/',
  });
}
```

**Adaptation notes:**
- File-level `'use server'` directive — required.
- `cookies()` is async in Next 16 (verified RESEARCH §7). DO NOT call `cookies()` synchronously.
- Validate `raw === 'dark'` defensively — anything else falls through to `'light'` (closed-enum guard, mirrors `KNOWN_ERROR_CODES` pattern in `(auth)/login/page.tsx:33-38`).
- Cookie attributes locked by D-C3: `sameSite='lax'` / `httpOnly=false` / `maxAge=31_536_000` / `path='/'`. NEVER `__Host-` prefix.
- DO NOT log the value — privacy convention #4 from CLAUDE.md (theme is non-sensitive but logging is unnecessary; if logging is added, use `event=theme_toggled` opaque event-name pattern).

### Pattern S-4: RSC `cookies()` + `getCurrentUserCached()` for auth-aware reads

**Source:** `apps/web/app/layout.tsx:74-89` (cached pattern), `apps/web/features/account/api/me.ts:64-72` (cache wrapper definition)
**Apply to:** TopBar, Hero (auth-aware CTA), any future RSC that reads `/me`

```tsx
// app/layout.tsx:74-78

```

```tsx
// features/account/api/me.ts:64-72 — cache definition
export const getCurrentUserCached = cache(
  async (cookieHeader: string | undefined): Promise<CurrentUser> => {
    if (cookieHeader === undefined) return fetchCurrentUser();
    return fetchCurrentUser({ headers: { cookie: cookieHeader } });
  },
);
```

**Rules:**
- Pass `(await cookies()).toString()` as a primitive string — React `cache()` keys by value-equality for primitives (Phase 1.5 HIGH-2 fix).
- Wrap in try/catch with silent fallback — never block render on `/me` failure.
- Privacy: never log cookie value, response body, or correlate locale with email.
- DO NOT call `cookies().set()` from a Server Component render path (RESEARCH §3 Gotcha 3 — Next throws at runtime).
