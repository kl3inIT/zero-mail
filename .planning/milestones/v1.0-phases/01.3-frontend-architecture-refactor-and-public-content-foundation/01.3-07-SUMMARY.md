- **Cast-bypass cleanup folded into Task 2** even though the 4 source files (`(public)/page.tsx`, `(public)/layout.tsx`, `(public)/docs/page.tsx`, `(public)/docs/[slug]/page.tsx`) are not in the plan's `<files>` block. - **Onboarding page + ConnectionHealthBadge `as never` retained.** Those are dynamic-key indexing where the key string is a runtime variable from a typed union (template-key registry, status enum). They are NOT missing-key bypasses; out of scope for Plan 07's "Plan 04/05/06 source" target.
- **Strict-mode flip committed BEFORE block-test, not after.** If the flip hadn't been committed first, the temp branch would have inherited the parent commit's `|| true` and the deliberate-drift commit would have succeeded — falsely "passing" the verification. Ordering matters; this is now documented in `patterns-established`.
