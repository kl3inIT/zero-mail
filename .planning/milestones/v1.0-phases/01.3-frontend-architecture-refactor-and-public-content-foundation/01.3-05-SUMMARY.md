## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] Repoint app/[locale]/* re-exports during Task 1**

- **Found during:** Task 1 — running tsc after `git mv`-ing pages and deleting `app/page.tsx`.
- **Issue:** The 4 dead re-export files in `app/[locale]/` pointed at moved/deleted source paths, breaking tsc with `Cannot find module '../page'` etc.
- **Fix:** Repointed each re-export at its new group-relative path (`../page` → `../(auth)/login/page` for /login; same pattern for /onboarding, /settings; `../page` → `../(auth)/login/page` for the [locale] root since (public)/page.tsx didn't exist yet at Task 1). Comments mark them as Plan-05 Task-5 deletion targets.
- **Why not just delete them at Task 1:** The plan explicitly gates [locale]/ deletion behind a Playwright route-smoke (REVIEWS Rev 2 #5). Repointing was the minimal-impact way to keep tsc green between Tasks 1 and 5.
- **Files modified:** `apps/web/app/[locale]/page.tsx`, `apps/web/app/[locale]/login/page.tsx`, `apps/web/app/[locale]/onboarding/page.tsx`, `apps/web/app/[locale]/settings/page.tsx`.
- **Commit:** `bec916b` (Task 1) — files later deleted in `0efd9bb` (Task 5).

**2. [Rule 3 — Blocking] next-intl typed namespace bypass via cast-to-never**

- **Found during:** Task 1 — tsc errored on `getTranslations('common.nav')` because the namespace doesn't exist in messages/{vi,en}.json yet (Plan 07 will add it). Same issue on `t('landing.heading')` etc. in Task 3.
- **Issue:** The plan's `<interfaces>` block uses `getTranslations('common.nav')` and `t('landing.heading')`. With next-intl v4 typed messages, these fail tsc until the namespace lands.
- **Fix:** Use unscoped `getTranslations()` and cast missing key paths with `as never` (e.g., `t('common.nav.docs' as never)`). Runtime returns the key path itself as a safe fallback — same effect as the plan's "those keys may resolve to fallback raw strings" note.
- **Files modified:** `apps/web/app/(public)/layout.tsx`, `apps/web/app/(public)/page.tsx`.
- **Commits:** `bec916b` (Task 1), `7e44ca4` (Task 3).

**3. [Rule 2 — Missing critical functionality] Update scripts/check-i18n.ts EN_SCAN_FILES**

- **Found during:** Final verification — `pnpm run i18n:check` exited 1 with `cannot read app/login/page.tsx (file missing)` × 3.
- **Issue:** EN_SCAN_FILES still pointed at flat-tree paths after Task 1 relocations. Same Phase 1.1 D-D3 contract that Plan 04 Task 1 had to update.
- **Fix:** Updated 3 entries to route-group paths and added 2 new entries for (public)/page.tsx and (public)/layout.tsx. Coverage went 8 → 10 Phase 1 files.
