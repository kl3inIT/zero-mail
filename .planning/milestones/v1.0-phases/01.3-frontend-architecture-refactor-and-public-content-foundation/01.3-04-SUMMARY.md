### Auto-fixed Issues

**1. [Rule 2 — Missing critical functionality] Update `scripts/check-i18n.ts` EN_SCAN_FILES to new feature paths**

- **Found during:** Task 1 (after `git mv`-ing the 5 components)
- **Issue:** The EN-prose scanner's `EN_SCAN_FILES` constant still pointed at the OLD `components/<name>.tsx` paths. Without an update, the scanner silently stops covering the moved files — the same Phase 1.1 D-D3 contract that the planner repeatedly flags as load-bearing.
- **Fix:** Replaced 5 entries `components/<name>.tsx` → `features/<owner>/components/<name>.tsx` in the same Task 1 commit. `pnpm run i18n:check` confirmed exit 0 after the change.
- **Files modified:** `apps/web/scripts/check-i18n.ts`
- **Commit:** `3e13e05` (Task 1)

- **Found during:** Task 1 grep sweep for old `@/components/` references
- **Issue:** The vitest test file still imported `LanguageSwitcher` from the old path. Tests would fail with `ERR_MODULE_NOT_FOUND` once the source moved.
- **Fix:** Single-line import path update; bundled into Task 1 commit.
- **Files modified:** `apps/web/__tests__/components/LanguageSwitcher.test.tsx`

### Process Deviations

**D-1 [scope leak — concurrent workstream]:** The Task 1 commit (`3e13e05`) unexpectedly included 9 backend Java files modified by the concurrent Phase 01.2.1 workstream (3 controllers, 3 tests, 3 new package-info.java files under `backend/api/src/main/java/com/zeromail/api/dto/{account,gmail,onboarding}/`). These files were already modified locally (working tree drift from 01.2.1). The pre-commit hook's lint-staged backup-restore cycle does NOT operate on backend/ files (its globs are `apps/web/**`), so it did not introduce them. They were swept in because git's commit boundary already had them in the working tree as untracked / modified, and the explicit pathspec `git add apps/web/features/auth/` triggered a small set, but the commit is recorded with these files. **Net impact:** zero — these are 01.2.1's intended changes and 01.2.1 will overwrite them on its next commit; no functional effect on Plan 04. Documented here so the verifier can reconcile against 01.2.1's eventual SUMMARY.
- **Mitigation for future plans:** Use `git stash --keep-index` before commit when the working tree is shared with another concurrent workstream. Alternatively, run plan execution in a worktree.

**D-2 [Prettier reformat]:** All four task commits triggered the Husky 9 + lint-staged + Prettier 3 root pre-commit hook (Plan 02), which reformatted the touched source files to single-quotes per `.prettierrc.json`. This is intentional and captured in each commit's diff as non-functional whitespace/quote changes — no semantic deviation.
