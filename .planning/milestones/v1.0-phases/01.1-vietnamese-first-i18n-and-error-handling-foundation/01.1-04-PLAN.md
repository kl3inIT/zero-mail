|----------|-------------|
| Untrusted PATCH body → users.preferred_language | language string crosses from network into DB |
| Authenticated principal A → tenant B's user row | Cross-tenant write attempt |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1.1.04-01 | Tampering | language field accepts arbitrary string | mitigate | `@Pattern(regexp="vi|en")` Bean Validation + DB CHECK constraint (defense in depth) |
| T-1.1.04-02 | Elevation of Privilege | Cross-tenant locale mutation | mitigate | Tenant-scoped JPA repository `findFirstByTenantId(tenantId)` — verified by `patchMeLanguage_isTenantScoped_doesNotMutateOtherTenants` |
| T-1.1.04-03 | Tampering | CSRF on PATCH /me/language | mitigate | Spring Security 7 CookieCsrfTokenRepository (Phase 1 baseline) — no change required |
| T-1.1.04-04 | Information Disclosure | Validation error leaks exception class names / SQL state | mitigate | GlobalExceptionHandler (Plan 02) emits only code+fieldErrors+filtered params; integration test asserts no `ConstraintViolation`/`org.hibernate`/`MethodArgumentNotValidException` substrings appear |
| T-1.1.04-05 | Information Disclosure | Server-built localized prose in response | mitigate | Controller does not call MessageSource; verified by grep + ArchUnit ban (Plan 08) |
