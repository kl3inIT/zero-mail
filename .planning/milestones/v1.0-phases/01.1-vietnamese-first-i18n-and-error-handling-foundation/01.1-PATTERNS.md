### `AllowedParamScalars.java` (utility, transform)

**Analog:** none in repo. New pattern. Cite RESEARCH.md Pitfall 5.

**Pattern (planner-authored skeleton):**
```java
package com.zeromail.api.error;

import java.util.*;

public final class AllowedParamScalars {
    /** Accept only scalars FE can safely render via ICU placeholders. */
    public static Map<String, Object> filter(Object[] args) {
        if (args == null) return Map.of();
        Map<String, Object> out = new LinkedHashMap<>();
        int i = 0;
        for (Object a : args) {
            if (a instanceof Number || a instanceof Boolean) {
                out.put("arg" + i, a);
            } else if (a instanceof String s && s.matches("[a-zA-Z0-9_.\\-]{1,64}")) {
                // dotted dictionary keys / enum names / resource ids only
                out.put("arg" + i, s);
            }
            i++;
        }
        return out;
    }
    private AllowedParamScalars() {}
}
```
**Safety invariant:** the `D-D4` integration test asserts that seeding `<script>`, refresh-token shapes, SQL constraint names, prompt-injection text into validation arguments never appears in the response body or logs.
