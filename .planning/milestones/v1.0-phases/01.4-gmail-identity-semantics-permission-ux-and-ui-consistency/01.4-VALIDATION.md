## Sampling Rate

- **After every task commit:** Run quick command for the touched module (`./gradlew :backend:api:test --tests "*GmailOAuth*"` for backend tasks, `pnpm --filter zeromail-web test -- <FileName>` for frontend tasks).
- **After every plan wave:** Full backend suite + full Vitest suite (Playwright smoke deferred to phase gate).
- **Before `/gsd-verify-work`:** Full suite green + `pnpm --filter zeromail-web run i18n:check` green + `pnpm --filter zeromail-web run lint` green.
- **Max feedback latency:** ~30s for quick run; ~3min for full suite.
