## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client form → /api/byok | API key entered in `<input type="password">`; submitted via openapi-fetch over HTTPS |
| server response → client | Server never returns plaintext — `lastFourChars` field renders the masked display |
| schema codegen | Generated `schema.d.ts` is build artifact; hand-edits forbidden |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-06-01 | Information disclosure | Plaintext key in browser local storage or query cache | mitigate | Never store the plaintext key in TanStack Query cache; the save mutation has no `keepPreviousData`; on success the cache invalidates and re-fetches the masked response |
| T-09-06-02 | Tampering | FE allows OPENROUTER selection | mitigate | Provider `<Select>` options literal list `{OPENAI, ANTHROPIC, GOOGLE, DEEPSEEK}` — OPENROUTER/ROUTER_9R never rendered (defense in depth with backend allow-list) |
| T-09-06-03 | Tampering | FE activates BYOK without test | mitigate | Active `<Switch>` is `disabled` while `modelId == null || lastTestResult !== 'OK'`; tooltip explains; backend gates as well (plan 09-04 task 3) |
| T-09-06-04 | Information disclosure | Hardcoded color hex bypasses palette pivot | mitigate | ESLint gate `no-hardcoded-color-hex` + repo grep; design tokens only (per AGENTS.md token policy) |
| T-09-06-05 | Tampering | Hand-edits to schema.d.ts | mitigate | Generated file regenerated after backend boots; PR check via `pnpm --filter web run generate:api && git diff --exit-code` |
| T-09-06-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed (all primitives present per UI-SPEC § Registry Safety) |
</threat_model>
