## Decisions Made

- Kept examples/actions DB-backed, not frontend hard-coded; UI plans must consume generated API types.
- Kept admin catalog APIs under `/api/admin/rule-catalog/**` with class-level `@PreAuthorize("hasRole('ADMIN')")` and `AdminContext.currentOrThrow()`.
- Chose an isolated OpenAPI compose file instead of enabling the production compose file during codegen. The production compose includes deploy services and external networks; codegen only needs Postgres and Redis.
