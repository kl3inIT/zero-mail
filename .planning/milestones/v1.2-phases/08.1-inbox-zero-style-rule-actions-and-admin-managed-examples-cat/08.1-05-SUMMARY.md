## Decisions Made

- Runtime execution for expanded actions is intentionally not enabled in this plan. Triage still rejects unsupported runtime execution until 08.1-06 adds the shared outbound gateway and safety gates.
- `body` remains a permitted action JSON key only for user-authored draft/send payloads. Domain record fields avoid sensitive raw-name flags by storing the record component as `draftBody`.
- Direct safe LLM action tools are still limited to label/archive/save_draft so expanding `Action` does not accidentally allow direct outbound tool calls.
- RACT-11 remains pending for 08.1-06 because the full low-trust/static sender runtime guard belongs with the outbound gateway execution path.
