**DB-backed persona examples now live inside the existing rule composer, with catalog-backed action visibility and one global Auto-send rules setting.**

## Accomplishments

- Added generated-schema web API calls and locale-aware hooks for rule examples, action descriptors, and automation settings.
- Replaced the old three hard-coded composer suggestions with DB-backed persona examples under `Choose from examples`; clicking an example replaces the textarea exactly.
- Added a catalog-backed `AvailableActionsPanel` that shows Label, Archive, Save draft, Mark read, Star, Add to digest, Mark spam, Send reply, Forward, and Send email.
- Added one Settings switch for `Auto-send rules`; when off, outbound UI explains Gmail draft fallback instead of blocking rule saves.
- Added unit and Playwright coverage for composer examples, action panel outbound copy, desktop/mobile browser flow, and settings persistence.
