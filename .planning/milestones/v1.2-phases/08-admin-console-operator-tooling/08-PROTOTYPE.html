About this prototype

Throwaway static mockup. Not wired to APIs. Generated by /gsd-ui-phase 8 alongside 08-UI-SPEC.md. Tokens, typography, spacing, and copy match the locked contract. Inline CSS via Tailwind CDN.

Out of scope
  • Dark mode (deferred v1.3+)
  • Mobile responsive below 1024px
  • Internationalization (admin EN-only)
  • Live WebAuthn ceremony JS
  • Real chart library (recharts in real app)
