## Sampling Rate

- **After every task commit:** Run quick command relevant to slice (backend → backend gradle test; frontend → vitest)
- **After every plan wave:** Run full suite command (gradle test + vitest + tsc + lint + i18n:check)
- **Before `/gsd-verify-work`:** Full suite must be green; manual `pnpm dev` walkthrough for polish surfaces
- **Max feedback latency:** 120 seconds
