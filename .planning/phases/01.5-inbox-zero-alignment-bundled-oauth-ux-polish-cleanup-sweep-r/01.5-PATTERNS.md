@Component
public class GoogleAuthorizationRequestResolver implements OAuth2AuthorizationRequestResolver {

    private static final String GOOGLE_REGISTRATION_ID = "google"; // was "google-gmail"
    private static final String RECONNECT_PARAM = "reconnect";
    private final DefaultOAuth2AuthorizationRequestResolver delegate;

    public GoogleAuthorizationRequestResolver(ClientRegistrationRepository repo) {
        this.delegate = new DefaultOAuth2AuthorizationRequestResolver(repo, "/oauth2/authorization");
    }

    @Override public OAuth2AuthorizationRequest resolve(HttpServletRequest req) {
        return customize(delegate.resolve(req), req);
    }
    @Override public OAuth2AuthorizationRequest resolve(HttpServletRequest req, String id) {
        return customize(delegate.resolve(req, id), req);

**`customize` rebuild pattern (current lines 39–60 — DROP `login_hint` injection, ADD `?reconnect=true` toggle per RESEARCH §A):**
```java
private OAuth2AuthorizationRequest customize(OAuth2AuthorizationRequest r, HttpServletRequest req) {
    if (r == null) return null;
    Object regId = r.getAttribute("registration_id");
    if (regId == null || !GOOGLE_REGISTRATION_ID.equals(regId.toString())) return r;
    var extra = new HashMap<>(r.getAdditionalParameters());
    extra.put("access_type", "offline");
    extra.put("include_granted_scopes", "true");
    if ("true".equals(req.getParameter(RECONNECT_PARAM))) {
        extra.put("prompt", "consent");
    }
    return OAuth2AuthorizationRequest.from(r).additionalParameters(Map.copyOf(extra)).build();
}
```

**`Map.copyOf(extra)` pattern preserved** — quick task `8qe` already shipped this immutability fix (STATE.md line 188).

### ScopedValue + Tx Ordering (Phase 1 D-B1 — Pitfall 6)

**Source:** `OAuthProvisioningService.java` lines 78–86 + `GmailOAuthSuccessHandler.java` lines 156–169.

**Apply to:** `GoogleOAuthSuccessHandler` (the bundled-flow atomic block).

```java
ScopedValue.where(TenantContext.TENANT, tenantId.toString())
        .run(() -> tx.executeWithoutResult(_ -> {
            // persistence calls here — Hibernate captures tenant on session open
        }));
```

**Order: bind ScopedValue → open tx → persist.** Not bind → persist (no tx) and not open tx → bind (Hibernate session opens with bootstrap tenant).

### Closed-Enum Tamper Guard for Frontend `?error=...` (Phase 01.4 Threat T-error-param-tamper)

**Source:** `apps/web/app/(protected)/onboarding/page.tsx` lines 46–53 (`ERROR_KEY_MAP` + `isKnownError` typeguard).

**Apply to:** new `/login` page error handling. Pattern guards against `?error=javascript:alert(1)` and unknown codes echoing into JSX text.

```tsx
const KNOWN_ERROR_CODES = ['consent_denied', 'gmail_scope_required'] as const;
function isKnownError(value: unknown): value is (typeof KNOWN_ERROR_CODES)[number] {
  return typeof value === 'string'
    && (KNOWN_ERROR_CODES as readonly string[]).includes(value);
}
```
