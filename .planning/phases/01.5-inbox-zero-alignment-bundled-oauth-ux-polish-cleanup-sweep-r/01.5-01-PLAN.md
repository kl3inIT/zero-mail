<objective>
Collapse the two-leg `google` + `google-gmail` OAuth architecture into a single bundled-scope `google` registration aligned with Inbox Zero's pattern. The success handler atomically provisions user + tenant + GmailConnectionEntity in one transaction; the failure handler maps OAuth2 errors to /login?error=... redirects with no half-provisioned DB state. Drop OnboardingStep.SIGNED_IN and delete all six 2-leg flow Java files plus their tests. Phase pivots AUTH-01/AUTH-02 implementation shape — no new product requirements.

Purpose: Match Inbox Zero's verified production pattern (single consent screen for everything you need), eliminate the mismatch-architecture surface, and remove dead code per D-A3 (no transitional aliases).

Output: Single bundled OAuth flow shipping with full test coverage and clean DB cleanup migrations.
</objective>
