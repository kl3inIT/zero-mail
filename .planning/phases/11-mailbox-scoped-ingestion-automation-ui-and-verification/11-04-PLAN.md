| send command → Gmail send | command's executing MailboxRef is the only authority for which mailbox sends |
| copy-rules → target mailbox | ownership of both source + target re-validated; cloned rules land disabled |

| T-11-04-02 | Elevation | another mailbox's rules evaluate for the source mailbox | mitigate | runtime load WHERE gmail_connection_id = :sourceMailbox AND enabled=true (AUTO-04) |
