<objective>
Thread the active mailbox through the ENTIRE ingestion path: Pub/Sub email→`(tenant, mailbox)` resolution (ING-01), per-mailbox history cursor + backfill + ingestion health + watch renewal + history-lost handling (ING-02), observed/projection writes keyed by `gmail_connection_id` (ING-03/06), and mailbox-aware Gmail client lookup — all while preserving the no-raw-body/log privacy posture (ING-05/AUD-07). This is the central ingestion refactor that also migrates the Plan 02 transitional event constructor's CALLERS (`GmailDeliveryProcessingService`, `BackfillNeedsReplyService`) to the mailbox-carrying constructor and REMOVES the transitional null-mailbox overload (HIGH-1 — no compile-broken seam). **HIGH-6 from 11-REVIEWS.md: ingestion scope is broader than a few files — watch renewal, history-lost handling, the backfill enqueuer's per-mailbox job idempotency, and ingestion health must all become mailbox-scoped, not tenant-scoped.**

Purpose: Make ingestion operate on the SPECIFIC connection that received the mail, not the tenant's primary via the shim. Eliminates the same-message-id collision and the cross-account cursor-poisoning hazards now that the schema (Plan 02) supports it.
Output: Pub/Sub lookup returns a mailbox, delivery processing routes through `buildClientForMailbox`, cursor/observed/projection/events carry the connection id.
</objective>
