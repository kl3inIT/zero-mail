<objective>
Thread the active mailbox through the entire ingestion path: Pub/Sub email→`(tenant, mailbox)` resolution (ING-01), per-mailbox history cursor + backfill + ingestion health (ING-02), observed/projection writes keyed by `gmail_connection_id` (ING-03/06), and mailbox-aware Gmail client lookup — all while preserving the no-raw-body/log privacy posture (ING-05/AUD-07). This is the central ingestion refactor that closes the gmail-package call sites left compiling-broken by the Plan 02 event extension.

Purpose: Make ingestion operate on the SPECIFIC connection that received the mail, not the tenant's primary via the shim. Eliminates the same-message-id collision and the cross-account cursor-poisoning hazards now that the schema (Plan 02) supports it.
Output: Pub/Sub lookup returns a mailbox, delivery processing routes through `buildClientForMailbox`, cursor/observed/projection/events carry the connection id.
</objective>
