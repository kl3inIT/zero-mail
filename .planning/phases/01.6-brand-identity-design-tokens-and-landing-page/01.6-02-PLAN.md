## Plan rationale

Typography lives in `app/layout.tsx` because `next/font/google` instances must be module-level so Next can statically extract font preloading metadata. This is independent of token rebinding (Plan 01.6-01) so they can run in parallel within Wave 1 — except both touch DIFFERENT files (`globals.css` vs `layout.tsx`) so file ownership is clean. The token plan adds `--font-serif` and updates `--font-sans` chain in `@theme inline`; this plan adds the actual `next/font` instances. Order between 01.6-01 and 01.6-02 within Wave 1 does not matter as long as both ship before Wave 2.

**Deviation from RESEARCH Q4 [400, 600]:** medium (500) added for nav and section heading emphasis (frontend-design skill convention requires medium-emphasis weight to differentiate from 400 body and 600 strong CTA). Verified in RESEARCH §Performance Budget — +30KB does not exceed Lighthouse mobile ≥ 90 ceiling. Recorded as Q4 RESOLVED in 01.6-RESEARCH.md.
