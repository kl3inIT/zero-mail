    STEP 2 — Create apps/web/features/analytics/utils/analyticsUtils.ts.

    This module consolidates the safeCount function (currently duplicated in VolumePanel.tsx,
    RuleHitsPanel.tsx, TopSendersPanel.tsx) and adds new utilities needed by delta badges and
    new panels.

    Export the following functions:

    safeCount(value: number | undefined): number
      Returns Number.isFinite(value) ? Math.max(0, Math.trunc(value ?? 0)) : 0
      Handles NaN, undefined, negative, non-integer inputs.

    formatDelta(deltaPct: number | null | undefined): string
      Returns "—" when deltaPct is null, undefined, or not finite.
      Returns "+N%" for positive, "-N%" for negative (sign always explicit).
      Examples: formatDelta(10) → "+10%", formatDelta(-5) → "-5%", formatDelta(null) → "—".

    deltaVariant(deltaPct: number | null | undefined): "positive" | "negative" | "neutral"
      Returns "neutral" when null/undefined/not-finite.
      Returns "positive" when deltaPct > 0.
      Returns "negative" when deltaPct < 0.
      Returns "neutral" when deltaPct === 0.

    precisionRate(decisions: number | undefined, applied: number | undefined): string
      Returns "—" when safeCount(decisions) === 0 (per D-16).
      Returns Math.round((safeCount(applied) / safeCount(decisions)) * 100) + "%" otherwise.

    trustBadgeVariant(decisions: number | undefined, applied: number | undefined): "default" | "secondary" | "destructive"
      Returns "secondary" when safeCount(decisions) === 0 (badge hidden per D-16).
      Computes pct = safeCount(applied) / safeCount(decisions) * 100.
      Returns "default" when pct >= 90 (teal — maps to text-teal-600 via shadcn Badge default variant).
      Returns "secondary" when pct >= 70 (amber).
      Returns "destructive" when pct < 70.

    File uses TypeScript, no React imports needed (pure functions).
    No default export — named exports only (per project conventions).
  </action>
