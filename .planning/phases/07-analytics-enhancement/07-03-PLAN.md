  because camelCase keys generate --color-saveDraft which is valid CSS.
  Actual RESEARCH.md recommendation: use action.replace(/_/g, '-') for CSS var name,
  keeping "save-draft" in ChartConfig (hyphens ARE valid in CSS custom property names).
  The ChartConfig object keys and data nameKey must match exactly.
