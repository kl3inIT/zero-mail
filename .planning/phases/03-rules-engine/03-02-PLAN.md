<objective>
Resolve the Phase 3 compile-contract gap inside `core.llm`: add a gateway-owned rule compile tool path and dedicated result type so `core.rules` can request structured rule compilation without importing Spring AI, passing arbitrary tools, or widening the safe Gmail action enum.

Purpose: RULE-02 requires structured tool-call output, but the current gateway only exposes safe action tools. This plan intentionally isolates rule compilation behind `LlmGateway.compileRule(...)` rather than refactoring the public `ToolCallResult` record that Phase 2C, worker drift, BYOK, and credit lifecycle paths already consume.
</objective>
