> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework (backend)** | JUnit 5 (Spring Boot 4.0.6 starter-test) + Testcontainers Postgres + ArchUnit |
| **Framework (frontend)** | Vitest + @testing-library/react + Playwright (smoke only) |
| **Config file (backend)** | `backend/core/build.gradle.kts`, `backend/api/build.gradle.kts` |
| **Config file (frontend)** | `apps/web/vitest.config.ts`, `apps/web/playwright.config.ts` |
| **Quick run command (backend)** | `./gradlew :backend:core:test :backend:api:test --tests "*I18n*" --tests "*Error*" --tests "*Locale*"` |
| **Quick run command (frontend)** | `pnpm --filter web test --run --testNamePattern "i18n|locale|error"` |
| **Full suite command** | `./gradlew check && pnpm -r test --run && pnpm --filter web exec playwright test` |
| **Estimated runtime** | ~90 seconds quick / ~6 minutes full |

---

## Sampling Rate

- **After every task commit:** Run quick command for the touched module (backend or frontend).
- **After every plan wave:** Run full suite for the affected module.
- **Before `/gsd-verify-work`:** Full suite green AND CI key-coverage check passes (vi/en parity).
- **Max feedback latency:** 90 seconds for quick; 6 minutes for full.
