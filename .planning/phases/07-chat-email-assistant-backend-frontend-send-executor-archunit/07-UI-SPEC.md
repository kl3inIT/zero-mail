# Phase 7 — UI Design Contract: Chat Email Assistant

> Visual and interaction contract for the `/chat` route, recipient-prominent preview cards, history sidebar, streaming/tool-call states, VIP banner, and "Added by AI" badge. Generated by gsd-ui-researcher from upstream `07-SPEC.md` + `07-CONTEXT.md` + locked design tokens in `apps/web/app/globals.css`.

**Scope reminder:** UI surfaces only for Phase 7 (chat shell, conversation pane, message bubbles, AI Elements primitives wrapping, preview cards, history sidebar, empty/loading/error states, replay-mode rendering). Settings UI is **Phase 8** (out of scope).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (initialized — `apps/web/components.json` present) |
| Preset | `base-nova` style, baseColor `neutral`, cssVariables on |
| Component library | Radix-based shadcn primitives in `@/components/ui/*` (already present: alert, button, card, dialog, dropdown-menu, input, popover, scroll-area, separator, sheet, sidebar, skeleton, sonner, switch, tabs, textarea, tooltip) |
| Icon library | `lucide-react` (locked in `components.json`) |
| Font | `--font-sans` (ui-sans-serif / system stack); `--font-mono` for eyebrows, timestamps, audit, code chips; `--font-serif` (Lora) reserved for accent quotes — NOT used in chat chrome |
| Vendored primitives | AI Elements at `apps/web/components/ai/*` (D-09; conversation, message, prompt-input, response, tool, reasoning, loader, suggestion, confirmation) + shadcn at `@/components/ui/*` — both excluded from ESLint/Prettier |
| Theme | Paper-warm neutrals; teal primary; violet/ink secondary; light + dark mode parity (`.dark` token variants already defined in `globals.css`) |

**Hard rule:** No new color, spacing, radius, or shadow tokens. Reuse `globals.css` tokens via Tailwind utilities (`bg-card`, `text-foreground`, `border-border`, `text-muted-foreground`, `bg-accent-soft`, `text-accent`, `text-ink`, `text-text-faint`, `shadow-sm/md/lg`, `rounded-md/lg`). The `zm-*` utility classes are **landing/auth-only** — do not pull them into `/chat` chrome.

## Spacing Scale

Declared values (must be multiples of 4). Anchors to existing `apps/web` patterns (`p-4 md:p-6`, `space-y-5`, `gap-4`).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`p-1`, `gap-1`) | Icon-to-label gap inside chips; badge inner padding |
| sm | 8px (`p-2`, `gap-2`) | Compact bubble inner padding; preview-card field row gap; button icon gap |
| md | 16px (`p-4`, `gap-4`) | Default — message bubble padding, preview-card inner padding, prompt-input padding, history-row padding |
| lg | 24px (`p-6`, `gap-6`) | Conversation pane outer gutters; sidebar section padding; empty-state panel padding |
| xl | 32px (`p-8`) | Major empty-state hero block; sidebar-to-pane gap on `lg+` breakpoints |
| 2xl | 48px | Reserved for vertical breathing room above the empty-state illustration block only |

**Exceptions:**
- Send-button focus ring uses Tailwind default 2px outline offset (`outline-ring/50` already in `@layer base`) — not on the 4px scale.
- AI Elements `prompt-input` internal heights inherit shadcn `<Textarea>` defaults — left untouched.
- History-sidebar item min-height 36px (matches shadcn `<SidebarMenuButton>`) — not on the 8px multiple but reused from existing primitive.

## Typography

Three sizes + one display ramp. All declared values map to existing `globals.css` token usage in `apps/web/features/rules`, `features/needs-reply`, `features/onboarding`.

| Role | Size | Weight | Line Height | Tailwind | Usage |
|------|------|--------|-------------|----------|-------|
| Body | 14px | 400 | 1.55 | `text-sm leading-relaxed` | Message bubble content, assistant streaming text, preview-card body, history-item title |
| Label | 12px | 500 | 1.2 | `text-xs font-medium` | Eyebrow (mono), preview-card field labels (To / Subject / Body), VIP banner, "Added by AI" badge, history timestamps, sidebar section headers |
| Heading | 17px | 600 | 1.3 | `text-[17px] font-semibold tracking-[-0.015em]` | Page H1 ("Trợ lý email"), preview-card title row, history sidebar header |
| Display | 22px | 700 | 1.15 | `text-[22px] font-bold tracking-[-0.02em]` | Empty-state hero line ("Bắt đầu trò chuyện với Zero Mail") — single instance only |

**Mono ramp** (auxiliary, NOT counted toward the 3-4 size rule — used only for system chrome):
- 11.5px mono uppercase letter-spacing 0.08em → eyebrows, timestamps, audit lines, tool-call status pill.

**Weights used:** `400` (body) and `600` (heading/label-emphasis). `500` appears via shadcn primitive internals — not a separate declared weight.

**Accent (#0E5E5A teal) reserved for:**
1. Primary Send button on preview card (the user-confirmed send commit action).
2. "Send message" button on prompt-input (submit the user prompt).
3. Active history-item left rail accent stripe (3px inset).
4. Streaming-cursor indicator (3px blinking dot, mirrors landing `zm-tester-cursor`).
5. Focus ring (`--ring`) — keyboard focus only.
6. Citation/tool-call link underline-color on hover.

**Never on:** plain text, navigation labels, body copy, secondary buttons, dividers, scrollbars, history-item titles, history-item delete buttons. (Anti-pattern: turning the chat chrome teal-y; the chat surface must read as paper + ink with teal punctuation.)

**Destructive (#B0413E):** Only on the "Cancel" / "Hủy gửi" button inside the preview card and the soft-delete confirmation dialog for chat history. Never on tool-call output cards, never on validation hints (use `text-muted-foreground` for inline validation).

## Message & Card Anatomy

### User message bubble
- Align right. `bg-secondary text-foreground rounded-2xl px-4 py-3 max-w-[78%]`.
- No avatar. Timestamp on hover only (`text-text-faint text-[11px] font-mono`).

### Assistant message bubble (streaming + final)
- Align left. `bg-accent-soft text-foreground rounded-2xl px-4 py-3 max-w-[82%]`.
- 22px round avatar `bg-ink text-background` with "ZM" mark (mirrors `.zm-brand-mark` shape) inline-start, `gap-2`.
- Streaming-state: trailing 7px × 13px teal cursor `bg-accent animate-pulse` after last token (steal the `zm-tester-cursor` idiom but with token color).
- Markdown rendered via `streamdown@2` — typography overrides: paragraph spacing `space-y-2`; code-inline `bg-muted px-1 rounded-sm font-mono text-[12.5px]`; code-block `bg-muted/60 rounded-md p-3 text-[12.5px]` (no extra border).

### Tool-call card (read tools 1-7 + write-reversible 8-15)
- Compact strip, `bg-card border border-border rounded-md p-3 my-2`.
- Header row: lucide icon (24×24, in `rounded-md bg-muted p-1`) + tool display name (`text-sm font-medium text-ink`) + status pill on the right.
- Status pill: `text-[11px] font-mono uppercase tracking-wider`, colors:
  - `running` → `bg-blue-soft text-blue` + animated 5px dot
  - `succeeded` → `bg-green-soft text-green` + check-icon
  - `failed` → `bg-red-soft text-red` + alert-circle
- Body: collapsed by default; click-to-expand chevron right. Expanded body shows sanitized tool output (NEVER raw email body — backend `ToolOutputSanitizer` enforces).

### Confirmation Preview Card (sendEmail / replyEmail / forwardEmail / createRule / deleteRule / saveMemory)

Single generic `<PreviewCard>` shell per D-13 (planner picks file decomposition). Visual contract:

```
┌─────────────────────────────────────────────────────────────────┐
│ [icon] Xem trước trước khi gửi                  • Cần xác nhận  │  ← header row: 17px semibold + mono eyebrow right
├─────────────────────────────────────────────────────────────────┤
│ [⚠ VIP] Người nhận có trong danh sách an toàn — vẫn gửi?       │  ← VIP banner (conditional, SET-SAFE-05)
│         ☐ Tôi đã xem kỹ và muốn gửi                            │     amber-soft bg + acknowledge checkbox
├─────────────────────────────────────────────────────────────────┤
│ ĐẾN     ceo@acme.com                                            │  ← field rows: label 12px mono uppercase
│ THÊM    charlie@partner.io  [Thêm bởi AI · xác minh]            │     blue-soft badge for outside-source recipients (req #17)
│ CC      (none)                                                  │
│ TIÊU ĐỀ Re: Đề xuất hợp tác Q3                                  │
│ NỘI DUNG ┌───────────────────────────────────────────────────┐  │
│         │ Chào anh Quang,                                    │  │  ← editable Textarea on Edit; read-only display by default
│         │ Cảm ơn anh đã chia sẻ đề xuất...                   │  │
│         └───────────────────────────────────────────────────┘  │
├─────────────────────────────────────────────────────────────────┤
│ [Chỉnh sửa]                          [Hủy]      [Gửi qua Gmail] │  ← secondary, ghost, primary teal
└─────────────────────────────────────────────────────────────────┘
   ↑ Send disabled while persisted-message-gate not yet satisfied
```

Component composition:
- Shell: shadcn `<Card>` (`bg-card border-border rounded-lg shadow-sm p-0`).
- Header row: `border-b border-border px-4 py-3 flex items-center justify-between`.
- VIP banner (conditional): shadcn `<Alert variant="default">` with manual amber tokens (`bg-amber-soft text-amber border-amber/20`), inline `<Checkbox>` "Tôi đã xem kỹ và muốn gửi".
- Field rows: `divide-y divide-border`. Each row `grid grid-cols-[80px_minmax(0,1fr)] gap-3 px-4 py-2.5`. Label uses `text-[11.5px] font-mono uppercase tracking-[0.08em] text-text-faint`.
- Outside-source recipient: inline pill `bg-blue-soft text-blue text-[11px] font-medium rounded-full px-2 py-0.5` with `<UserPlus>` icon — "Thêm bởi AI · xác minh".
- Body field: by default rendered text; on `Chỉnh sửa` click, swap to shadcn `<Textarea>` (auto-grow, `min-h-[140px] resize-y`).
- Footer: `border-t border-border px-4 py-3 flex justify-between gap-2`. Left = Edit (ghost). Right = Cancel (outline) + Send (primary, teal). When `createRule` / `deleteRule` / `saveMemory`, the right-most button label changes (see Copywriting Contract).
- Replay-mode (`status === 'confirmed'`): footer replaced by a single inline pill `bg-accent-soft text-accent text-[12px] font-medium rounded-full px-3 py-1` reading `Đã gửi lúc 14:32 ✓` — no buttons at all. Card surface dims to `opacity-90`.
- Cancelled replay (`status === 'canceled'`): pill `bg-muted text-muted-foreground` reading `Đã hủy lúc 14:32`. No re-execution; no buttons.

### Prompt input (bottom)
- shadcn `<Textarea>` with `min-h-[56px] max-h-[200px] rounded-lg bg-card border border-border focus-visible:ring-2 ring-ring`.
- Right-floating Send button (40×40 icon button, `bg-primary text-primary-foreground rounded-md`) with `<ArrowUp>` lucide icon. Disabled when textarea empty OR stream in-flight.
- During streaming: Send swaps to Stop button (40×40 `bg-muted hover:bg-secondary text-foreground rounded-md` with `<Square>` icon). Click → SSE `Disposable.dispose()` fires server-side.
- Below textarea (always-visible): tiny helper line `text-[11.5px] text-text-faint font-mono` — `Shift+Enter để xuống dòng · ⌘+Enter để gửi`. Hide on `<sm`.

### History sidebar
- Header: `text-[13px] font-semibold text-ink` + lucide `<MessageSquarePlus>` button (right) labeled `Mới` (tooltip-only on icon collapse).
- List: shadcn `<SidebarMenu>` (already in `components/ui/sidebar.tsx`). One row per conversation:
  - 1 line title `text-sm font-medium truncate` (assistant-generated title or first 40 chars of first user message).
  - Below title: `text-[11.5px] font-mono text-text-faint` showing `Hôm nay 14:32` / `Hôm qua` / `15 May`.
  - On hover/focus: lucide `<Trash2>` (16×16) appears at right; click → soft-delete confirmation dialog (shadcn `<AlertDialog>`, destructive primary).
  - Active conversation: 3px left rail `bg-accent`, row `bg-sidebar-accent`.
- NO rename button, NO search input (locked by SPEC requirement #7).
- Empty sidebar: a single muted line `Chưa có cuộc trò chuyện` + `text-text-faint text-[12.5px]` and a `Bắt đầu cuộc trò chuyện` link button.

## State Coverage

| State | Visual contract |
|-------|-----------------|
| **Empty conversation** (new chat, zero messages) | Centered block, `max-w-[480px]`. Lucide `<Sparkles>` 32×32 in `rounded-lg bg-accent-soft text-accent p-2`. Display heading "Bắt đầu trò chuyện với Zero Mail". Sub `text-muted-foreground text-sm leading-relaxed`: "Hỏi về inbox, quy tắc, hoặc soạn email — Zero Mail chỉ gửi sau khi bạn xác nhận." Below: 4 suggestion chips (shadcn `<Button variant="outline" size="sm">`) — `Liệt kê quy tắc đang bật`, `Tìm email từ Acme tuần này`, `Soạn email từ chối lịch sự`, `Lưu ghi chú: tôi đang làm dự án X`. |
| **Loading (history fetch)** | shadcn `<Skeleton>` rows in the conversation pane (3 bubble-shaped blocks alternating left/right) + sidebar skeletons (5 rows of `h-12 w-full`). |
| **Streaming (token-by-token)** | Assistant bubble renders incrementally; trailing 7×13 teal cursor `bg-accent animate-pulse`. Prompt-input swaps Send → Stop. Heartbeat is server-side only; no UI noise. |
| **Tool running** | Tool-call card with blue-soft status pill `Đang chạy` + animated dot. Conversation auto-scrolls. |
| **Confirmation pending** | Preview card renders with Send **disabled** until `chat_message.parts` persists; while disabled, Send shows `<Loader2 className="animate-spin">` and tooltip `Đang lưu...`. Once persisted, Send enables and tooltip clears. |
| **Confirmed (post-send, in-session)** | Card footer animates to "Đã gửi lúc HH:mm ✓" pill (fade-up 200ms). Conversation auto-appends a tiny assistant follow-up if backend emits one. |
| **Confirmed (replay after refresh)** | Same "Đã gửi lúc HH:mm ✓" pill but no animation. Card body remains visible in read-only display mode (no Edit button). |
| **Cancelled** | Pill `Đã hủy lúc HH:mm` in muted style. No further action possible on that card. |
| **VIP banner (SET-SAFE-05)** | Amber-soft banner inside preview card header; Send disabled until acknowledge checkbox checked. Checkbox uncheck → Send re-disables. |
| **Recipient outside source thread (req #17)** | Inline blue-soft pill next to each added recipient. NO modal, NO blocking. |
| **Error (stream failed mid-turn)** | Inline shadcn `<Alert variant="destructive">` inside conversation: title "Mất kết nối với trợ lý" + body "Hãy thử lại — tin nhắn của bạn vẫn được lưu." + ghost "Thử lại" button (re-trigger `useChat` `reload()`). NEVER auto-reconnect (`reconnectToStream` permanently disabled per SPEC). |
| **Error (tool-call failed)** | Tool-call card flips to red-soft pill `Lỗi` + expanded body shows `text-destructive text-sm` 1-line reason (sanitized). Conversation continues — assistant emits a follow-up turn. |
| **Cancel (Stop button)** | Stream halts immediately. Inline `text-text-faint text-[12.5px] italic` line below last bubble: `Đã dừng phản hồi`. |
| **History soft-delete confirm** | shadcn `<AlertDialog>` — title "Xóa cuộc trò chuyện?" + body "Bạn có thể khôi phục bằng cách liên hệ hỗ trợ trong 30 ngày." + destructive primary `Xóa`, secondary `Hủy`. |
| **Persistence-gate latency (>1s)** | Send button shows spinner; if gate not satisfied after 3s, show inline helper text `Đang đồng bộ — Gửi sẽ bật ngay khi sẵn sàng` below the footer. Never time out the gate client-side. |

- No auto-scroll override on user scroll-up (preserve scroll position when user is reading history).

## Accessibility

- Conversation viewport has `role="log"` + `aria-live="polite"`. Each new assistant token batch announces via the streaming aria-live label "Đang trả lời..." only on stream-start, not per-token.
- Preview card has `role="region"` + `aria-labelledby` pointing to the title row.
- VIP banner has `role="alert"` (the only place we use `role="alert"` — it's an interrupting safety check).
- Send button: `aria-disabled` + `aria-describedby` pointing to the persistence-gate helper line when disabled.
- All icon-only buttons (Stop, Delete, New) include `aria-label` from the copy table.
- Color contrast: every text-on-color combo above pulls from the v1.0-audited token set (already passes WCAG AA in `apps/web` per Phase 1.6 design audit). Do not introduce new combos.
- Keyboard: `⌘+Enter` / `Ctrl+Enter` submits prompt; `Esc` cancels in-flight stream; `Tab` order through preview card: Edit → Cancel → Send (left to right matching visual order).
