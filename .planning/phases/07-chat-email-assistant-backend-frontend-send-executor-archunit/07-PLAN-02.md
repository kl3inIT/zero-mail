## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Tool output → `chat_message.parts` JSONB | Pitfall 4 — sanitizer bypass persists email body |
| User personalization input → system prompt | ARCH-06 — sentinel injection / length attack |
| Concurrent send retry → audit table | ARCH-04 — duplicate audit row absent UNIQUE constraint |
| Schema version v1 → future v2 | Pitfall 11 — replay breaks if envelopes lack schemaVersion |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-06 | Information Disclosure | `chat_message.parts` carries email body extracted from Gmail | mitigate | 3-layer ban, source-aware (HIGH-3): Layer 1 source-aware sanitizer + Layer 2 source-aware ArchUnit (Wave 0) + Layer 3 source-aware Postgres trigger. All three reject body fields in email-read tool outputs (tool-getMessage / tool-searchInbox / tool-getThread / tool-listLabels) but allow body fields in send/draft tool args (tool-sendEmail / tool-replyEmail / tool-forwardEmail / tool-saveDraft) — user-authored draft is the carve-out path |
| T-07-07 | Tampering | Prompt-injected personalization escapes XML fence | mitigate | `PersonalizationSanitizer` strips 6 sentinels + caps 2000 + control-char strip; `XmlFencedPersonalizationRenderer` renders fence always (empty at GA) |
| T-07-08 | Repudiation | Duplicate audit row on retry (send OR write-reversible) | mitigate | `UNIQUE (chat_id, tool_call_id)` on `assistant_action_audit` (changelog 044) — applies to both confirmed-send rows and write-reversible rows, distinguished by `tool_category` |
| T-07-09 | DoS (data loss UX) | History replay breaks if envelope lacks schemaVersion | mitigate | D-08 — `schemaVersion: 1` literal in every envelope; `ChatPartsSchemaV1` dispatcher fails-loud on unknown version |
| T-07-10 | Information Disclosure | JPA entity without `@TenantId` lets cross-tenant query escape | mitigate | All entities extend `AbstractTenantOwnedEntity` (tenant discriminator inherited) |
