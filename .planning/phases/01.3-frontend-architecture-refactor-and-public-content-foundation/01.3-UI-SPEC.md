# Phase 01.3 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Scope Guardrails

| Decision | Contract |
|----------|----------|
| Phase surface | Scaffolding/chrome only: route-group layouts, public landing placeholder, docs index/article shells, loading/empty/error states. |
| Deferred design | Final landing/docs visual design, hero treatment, illustrations, marketing sections, docs sidebar/TOC/search/breadcrumbs, and content IA remain out of scope. |
| Existing UX | Preserve current `/login`, `/onboarding`, and `/settings` behavior while moving files into route groups/features. Do not change OAuth flow, session behavior, language persistence, or destructive-action semantics. |
| Copy source | All visible copy must come from `apps/web/messages/{vi,en}.json`; default language is Vietnamese, English is secondary. |
| Layout style | Quiet operational scaffold. No gradient/orb decoration, no stock imagery placeholders, no nested cards, no marketing polish. |

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui initialized in `apps/web/components.json` (source: `pnpm exec shadcn info`, 2026-04-26) |
| Preset | `base-nova`, base `neutral`, Tailwind CSS v4, RSC enabled |
| Component library | shadcn copied primitives backed by `@base-ui/react`; installed: `alert`, `badge`, `button`, `card`, `dialog`, `input`, `separator`, `skeleton` |
| Icon library | `lucide` for new icons; preserve the existing inline-SVG `LanguageSwitcher` exception until the documented React-dedupe issue is removed |
| Font | Geist Sans for UI text with `latin` + `latin-ext`; Geist Mono only for code-like docs snippets |

---

## Component Inventory

| Surface | Contract |
|---------|----------|
| `components/ui/*` | Remain shared primitives. Do not move or fork these during Phase 1.3. |
| Feature components | Move existing flat components to their locked feature owners: i18n, gmail, account, onboarding. Preserve props and copy keys. |
| Public chrome | Use a lean `(public)` header/footer with text logo, Docs link, Sign in/continue CTA, and compact `LanguageSwitcher`. |
| Auth chrome | Use a centered auth layout with the login card and compact `LanguageSwitcher`; no public nav inside auth. |
| Protected chrome | Extract protected header/chrome under `app/(protected)/_components/`; include `LanguageSwitcher`, leave future pause/balance/status slots visually stable but not implemented. |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, nav link gaps |
| md | 16px | Default element spacing, card content rhythm |
| lg | 24px | Page padding, auth card padding, docs article vertical rhythm |
| xl | 32px | Layout gaps between scaffold sections |
| 2xl | 48px | Major section breaks on landing/docs shells |
| 3xl | 64px | Page-level spacing; use sparingly because final marketing design is deferred |

Exceptions: `44px` minimum touch target for compact language switcher, chrome buttons, and any icon-only controls; `56px` minimum header row height for public/protected chrome. Existing shadcn radius tokens may remain, but new repeated cards must not exceed the existing `rounded-xl` primitive radius.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.4 |
| Heading | 20px | 600 | 1.2 |
| Display | 28px | 600 | 1.2 |

Typography rules: use only these four page-level sizes for new Phase 1.3 scaffold UI. Do not scale font size with viewport width. Letter spacing stays `0`. Reserve Display for the public landing title and docs page title only; route chrome, cards, and compact panels use Heading/Body/Label.

---

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--background)` = `oklch(1 0 0)` | Page backgrounds, full-width route-group shells |
| Secondary (30%) | `var(--muted)` / `var(--secondary)` = `oklch(0.97 0 0)` | Header/nav backgrounds, subtle docs list rows, protected chrome bands |
| Accent (10%) | `var(--primary)` = `oklch(0.205 0 0)` | Primary CTA buttons, active/current nav indicators, selected language check, selected onboarding template outline, docs text links |
| Destructive | `var(--destructive)` = `oklch(0.577 0.245 27.325)` | Destructive actions only: disconnect Gmail and delete account/data |

Accent reserved for: primary landing/auth CTA, active nav/current route state, selected language state, selected onboarding template outline (`ring-primary`; do not introduce new custom blue), and docs article links. Accent is not for decorative gradients, large background washes, every control hover state, or placeholder marketing visuals.

Status note: existing warning/disconnected UI may keep its current amber alert styling during the move, but Phase 1.3 must not introduce a new semantic palette beyond destructive.

## Interaction Contract

| Interaction | Contract |
|-------------|----------|
| Public landing CTA | Unauthenticated users link to `/login`. Authenticated users with incomplete setup link to `/onboarding`. If `/me` fails, silently default to `/login`; do not show a public API error. |
| Route links | Public nav uses visible focus states and `aria-current="page"` when applicable. Clean URLs remain `/`, `/login`, `/onboarding`, `/settings`, `/docs`, `/docs/[slug]`. |
| Language switcher | Same component in all route groups. Compact variant in public/auth/protected chrome, row variant only in settings. Preserve optimistic cookie write, authenticated PATCH, rollback on failure, and `router.refresh()` behavior. |
| Docs index | Server-rendered list of localized MDX entries. Empty state appears only when no docs exist for the current locale. No sidebar, TOC, search, or breadcrumbs in this phase. |
| Docs article | Server-rendered article shell with title, body, and a link back to docs. Missing locale/slug returns the docs not-found state, not raw filesystem/API errors. |
| Loading | Use `Skeleton` for protected client data where layout stability matters. Use localized `common.loading` only for simple inline pending states. |
| Errors | Localize API errors through the existing ApiError helpers. Never render raw exception messages or log API response bodies. |
| Disabled/pending | Buttons and menu items must keep dimensions stable while pending; loading text must not resize the control. |
| Destructive actions | No new destructive actions. Preserve account deletion typed-confirmation and Gmail disconnect behavior during the refactor. |
