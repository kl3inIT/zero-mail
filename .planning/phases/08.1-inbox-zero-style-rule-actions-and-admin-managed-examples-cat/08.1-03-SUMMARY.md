## Decisions Made

- Disabled catalog rows remain visible in the admin UI with switch OFF. The user-facing catalog still filters disabled data at the backend, but admin must keep rows reachable for re-enable/edit.
- Toggle/reorder actions use a fixed admin UI audit reason. This avoids turning a simple admin catalog tool into a CMS-style workflow.
