# Phase 01.4 Plan 01: Wave 0 Test Scaffolds Summary

**One-liner:** 14 RED-by-design test files (5 backend + 9 frontend) reference future Gmail OAuth identity classes, 5 UI primitives, 4 error/404 boundary surfaces — establishing the acceptance contract Waves 1–2 must satisfy.

## What Landed

### Backend — 5 files

1. **`GmailOAuthSuccessHandlerIntegrationTest.java`** — RED references `GmailOAuthSuccessHandler` + `GmailIdentityMismatchException` (cả hai chưa tồn tại). 3 test:
   - `successPath_matchingSubject_upsertsConnectionAndAdvancesStep`: identity-match → row CONNECTED, refresh-token round-trip qua AES-GCM, scopes filtered xuống gmail-prefix-only, onboarding bước SIGNED_IN → GMAIL_CONNECTED.
   - `idempotentReGrant_updatesExistingRowNoDuplicate`: invariant single-row-per-tenant; second grant updates in place, version increment, connectedAt bumped.
   - `mismatchedSubject_throwsGmailIdentityMismatchException_andWritesNoRow`: typed exception, không ghi row, onboarding step giữ nguyên.

2. **`GmailOAuthFailureHandlerIntegrationTest.java`** — RED references `GmailOAuthFailureHandler`. 3 test:
   - `identityMismatch_redirectsToOnboardingWithErrorCode_andRevokesToken`: redirect `/onboarding?error=gmail_identity_mismatch` + POST revoke endpoint.
   - `consentDenied_redirectsToOnboardingWithErrorCode_noRevoke`: `?error=gmail_consent_denied`, không revoke (không có token).
   - `revokeEndpoint5xx_doesNotBlockRedirect`: best-effort revoke; 5xx không block UX redirect.
   - Dùng `@DynamicPropertySource` override `google.revoke.base-url` → MockGoogleRevocationServer ephemeral port.

3. **`GmailScopeRequestResolverTest.java`** — RED references future `login_hint` extension. 2 test:
   - `loginHintInjected_whenAuthenticatedSession`: SecurityContextHolder có authenticated principal → `login_hint=<email>` xuất hiện cùng `prompt=consent`/`access_type=offline`/`include_granted_scopes=true`.
   - `loginHintOmittedGracefully_whenAnonymousSession`: anonymous → key vắng (không null), không exception.
   - Compile được (resolver class hiện tại tồn tại); FAIL ở runtime cho đến khi Plan 02 thêm `login_hint` vào `customize()`.

4. **`MockGoogleRevocationServer.java`** (test fixture, package `testfixtures`) — JDK `com.sun.net.httpserver.HttpServer` bound localhost ephemeral port. API: `start()`, `port()`, `stop()`, `getReceivedTokens()`, `setNextResponseStatus(int)`, `clearReceivedTokens()`. Best-effort stub theo spec `https://developers.google.com/identity/protocols/oauth2/web-server#tokenrevoke`. Compile sạch (chỉ phụ thuộc JDK + JUnit).

5. **`GmailConnectionServiceUpsertTest.java`** (core module, extends `PostgresContainerTest`). 3 test:
   - `upsert_insertsNewRowOnFirstCall`: insert mới với status=CONNECTED + refresh-token bytes round-trip.
   - `upsert_updatesExistingRowOnSecondCall_singleRow`: single-row invariant qua re-grant + version increment + scopes/token bytes win second-call.
   - `upsert_resetsDisconnectedAtAndStatus`: re-grant trên row DISCONNECTED → status=CONNECTED + disconnectedAt=null (D-A4 contract).

### Frontend — 9 files

5 primitive contract tests (all import từ `@/components/ui/<Primitive>` chưa tồn tại):

6. **`StatusAlert.test.tsx`**: cva variants info/success/warn/error, i18n keys via `useTranslations` (titleKey/bodyKey), destructive token classnames check (no raw `text-red-*`/`bg-red-*`/`text-stone-*`), CTA onClick invocation, ICU params.

7. **`EmptyState.test.tsx`**: title+body resolved strings, custom icon via JSX prop, CTA as `<Link className={buttonVariants()}>` (NOT `<Button asChild>` — UI-SPEC §Interaction Contracts), omits CTA region khi prop missing.

8. **`PageShell.test.tsx`**: `<main>` element, container max-width per variant (app=`max-w-3xl` default / marketing=`max-w-5xl` / docs=`max-w-3xl` / auth=`max-w-md` + centered flex).

9. **`SectionCard.test.tsx`**: heading/description/footer slots + body children; omits header region khi cả heading + description đều vắng.

10. **`LoadingState.test.tsx`**: skeleton placeholder count per variant — card (default ≥3), list (≥5), page (≥2 với header+body shape).

3 error/404 boundary tests (import từ `@/app/...` chưa tồn tại):

11. **`app/error.test.tsx`** (protected segment): renders title/body via `errors.boundary.*` keys, KHÔNG render `error.message`/`error.stack` (privacy contract — Threat T-error-leak), invokes `unstable_retry` prop (Next 16.2+), `console.error` gated by `NODE_ENV !== 'production'`.

12. **`app/global-error.test.tsx`**: own `<html>`/`<body>` (root replacement), English-only fallback (no next-intl provider), no `error.message` render, invokes `unstable_retry`, **fallback to `window.location.reload()` khi `unstable_retry` throws** (Plan 05 Task 1 File 1 contract — full reload là escape an toàn duy nhất khi root replacement broken).

13. **`app/not-found.test.tsx`**: server component pattern (`vi.mock('next-intl/server', ...)` cho `getTranslations`), `errors.notFound.title`/`body`/`backHome`, link href="/".

14. **`app/onboarding-error.test.tsx`** (mismatch alert wiring trên `/onboarding`):
    - Closed-enum URL param mapping: `gmail_identity_mismatch` + `gmail_consent_denied` → render StatusAlert; **arbitrary values (`error=javascript:alert(1)`) → no alert** (Threat T-error-param-tamper).
    - Retry CTA fires **BOTH side effects** independently and non-collapsibly (Plan 06 Task 1 step 6 contract):
      1. `window.location.href = '/tenant/connect-gmail'` (full-page nav to OAuth init — what user observes).
      2. `router.replace('/onboarding')` (URL hygiene cleanup).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 — Blocking] `@testing-library/user-event` không khả dụng**
- **Found during:** Task 2 first vitest run.
- **Issue:** Plan đề cập `userEvent` nhưng package không có trong `apps/web` dependencies. Vitest fail với "Failed to resolve import @testing-library/user-event" — không thể compile test.
- **Fix:** Dùng `fireEvent` từ `@testing-library/react` (đã có sẵn). Đây là pattern existing `LanguageSwitcher.test.tsx` đã áp dụng.
- **Files modified:** StatusAlert.test.tsx, error.test.tsx, global-error.test.tsx, onboarding-error.test.tsx.
- **Commit:** 7085551

**2. [Rule 3 — Blocking] next-intl strict typed bundle reject local test messages**
- **Found during:** Task 2 `tsc --noEmit`.
- **Issue:** Project xài typed message bundle (`apps/web/messages/en.json` shape). `NextIntlClientProvider` từ chối cấu trúc messages cục bộ tối thiểu vì `errors.boundary` không thuộc shape `errors` của bundle thực (TS2322).
- **Fix:** Cast `messages as never` ở 3 file (StatusAlert, error, not-found). Comment giải thích: cast giữ test bundle minimal cho contract đang exercise; không ảnh hưởng runtime vì next-intl chỉ dùng key lookup tại runtime.
- **Files modified:** StatusAlert.test.tsx, error.test.tsx, not-found.test.tsx.
- **Commit:** 7085551

**3. [Rule 3 — Blocking] `vi.fn()` không callable trong Proxy `set` trap với strict mode**
- **Found during:** Task 2 `tsc --noEmit`.
- **Issue:** `Mock<Procedure | Constructable>` của vitest không suy ra callable đúng khi gọi từ Proxy set handler (TS2348).
- **Fix:** Cast `vi.fn() as unknown as ((value: string) => void) & { mock: ... }` để TS narrow type.
- **Files modified:** onboarding-error.test.tsx.
- **Commit:** 7085551
