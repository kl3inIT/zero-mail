<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Gmail API → backend | Per-tenant access to user's Sent folder; tokens via existing OAuth refresh cipher |
| backend memory → LLM | Raw email bodies → prompt → completion; all bytes in-process |
| backend → DB / log / audit | MUST NOT persist prompts, completions, or bodies (D-11) |
| /api/settings/voice/generate-from-sent → client | Response carries the user-reviewable style guide string only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05-01 | Information disclosure | Spring AI observation captures prompt/completion to spans/logs | mitigate | Explicit `spring.ai.chat.client.observations.include-prompt=false` (+ matching completion key) in both api + worker application.yml; property-binding test asserts FALSE at boot (Pitfall 1) |
| T-09-05-02 | Information disclosure | llm_call_audit row persists prompt/completion via PREVIEW CallSite | mitigate | Verify PREVIEW CallSite skips prompt/completion columns OR doesn't write a row; sentinel-leak test confirms |
| T-09-05-03 | Information disclosure | Service logs "User Sent body length=N" with body excerpt | mitigate | Per CONVENTIONS §5: ONLY structured fields `event=voice.generate.completed tenantId={} sampleSize={} resultWordCount={}` — never any body excerpt; sentinel-leak test asserts |
| T-09-05-04 | Information disclosure | Exception messages leak body content | mitigate | Catch every checked exception inside service; wrap with sanitized error event before re-throwing/returning |
| T-09-05-05 | Tampering | Prompt-injection from user's own past sent emails | accept | The user is the source of their own emails; output is user-reviewed before save; PersonalizationSanitizer applies on Save path (handled by 09-02) |
| T-09-05-06 | Denial of service | Spam-trigger LLM calls | mitigate | Rate limit 3/h via `ByokRateLimiter` keyed on `voice.generate` |
| T-09-05-07 | Information disclosure | Generated style auto-saved containing email fragments | mitigate | Endpoint NEVER persists — caller (FE) must explicitly call `PUT /api/settings/voice` after user review; integration test asserts endpoint writes zero rows to assistant_settings |
| T-09-05-08 | Repudiation | No audit of generate trigger | accept | App-log structured event suffices; user is doing work on their own setting |
| T-09-05-SC | Tampering | npm/pip/cargo installs | accept | No new packages |
</threat_model>
