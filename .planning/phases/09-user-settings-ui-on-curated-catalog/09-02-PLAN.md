<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → REST | User-typed writing style, personal instructions, signature, knowledge snippets, tone preset, behavior toggles |
| chat tool → service | `ADD_TO_KNOWLEDGE_BASE` and `UPDATE_PERSONAL_INSTRUCTIONS` must reach the same sanitizer / persistence path as REST (single-call-site invariant) |
| worker → assistant_settings | DraftReplyWorker and SensitiveDataRedactor read per-tenant flags before acting |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-01 | Tampering | Personal instructions prompt-injection sentinels | mitigate | Single shared `PersonalizationSanitizer.sanitize(...)` call site enforced by `PersonalizationSanitizerSingleCallSiteTest` (ArchUnit) |
| T-09-02-02 | Information disclosure | Cross-tenant knowledge snippet read/delete | mitigate | Repository queries always include `tenant_id = ?`; controller calls `AssistantKnowledgeService.{find,update,delete}ByIdAndTenant`; cross-tenant returns 404 (not 403 — opaque) |
| T-09-02-03 | Tampering | Duplicate snippet titles bypass UNIQUE | mitigate | DB-level `UNIQUE(tenant_id, title)` enforced (Wave 0); service catches `DataIntegrityViolationException` and returns HTTP 409 `code=knowledge.title.duplicate` |
| T-09-02-04 | Spoofing | Toggle PUT without auth | mitigate | All controllers gated by existing user `SecurityFilterChain` (cookie session, not stateless JWT per CLAUDE.md) |
| T-09-02-05 | Information disclosure | Logging of writing_style / personal_instructions content | mitigate | Per CONVENTIONS §5: structured `event=settings.voice.updated tenantId={}` only; no body content in logs |
| T-09-02-06 | Tampering | Sensitive-data toggle OFF leaks PII to LLM | accept | User-controlled opt-out; default ON; logged as audit event when toggled |
| T-09-02-07 | Tampering | tone_preset not enforced server-side | mitigate | DB CHECK constraint (Wave 0) + Bean Validation `@Pattern` + service-layer `fromId` fail-loud helper |
| T-09-02-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed |
</threat_model>
